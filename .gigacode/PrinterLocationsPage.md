## Общий вид страницы

[![Скриншот: Общий вид страницы](../docs/screenshots/printer_locations_overview.png)]

Страница отображает список групп (локаций) принтеров. Каждая группа — карточка с названием, иконкой, цветовой меткой и количеством принтеров.

**Элементы интерфейса:**
- **Заголовок** — "Printer Locations" с подсказкой о количестве сгруппированных и несгруппированных принтеров
- **Поисковая строка** — фильтрация групп по названию
- **Кнопки управления** — "Hide/Show empty", "Select", "New Location"
- **Список групп** — карточки с раскрытием до списка принтеров
- **Ungrouped Printers** — секция с принтерами без группы

## Создание группы

[![Скриншот: Создание группы](../docs/screenshots/printer_locations_create.png)]

**Кнопка:** "New Location" (зелёный плюс) в верхней панели.

**Возможности модалки создания:**
- Ввод названия группы
- **Выбор иконки** — 31 иконка из lucide-react (IconPicker)
- **Выбор цвета** — 9 пресетов (красный, оранжевый, жёлтый, зелёный, бирюзовый, синий, фиолетовый, розовый, серый) + кнопка сброса
- Сохранение иконки и цвета происходит сразу при создании

**Технические детали:**
- Группа создаётся пустой — принтеры назначаются вручную через кнопку "Move"
- Название кэшируется в `localStorage` (`printerLocationsCache`) для автодополнения
- Иконка и цвет сохраняются в `printerLocationIcons` и `printerLocationColors`

## Редактирование группы

[![Скриншот: Редактирование группы](../docs/screenshots/printer_locations_edit.png)]

**Кнопка:** "✏️ Edit" (карандаш) справа от названия группы.

**Возможности модалки редактирования:**
- Изменение названия группы (с проверкой на дубликаты)
- Изменение иконки (переиспользуется IconPicker)
- Изменение цвета (те же 9 пресетов)
- При переименовании старая иконка и цвет автоматически удаляются

**Технические детали:**
- Состояние загрузки блокирует кнопку "Save"
- При ошибке модалка закрывается и состояние очищается
- Все изменения применяются ко всем принтерам в группе

## Раскрытие группы — список принтеров

[![Скриншот: Раскрытая группа](../docs/screenshots/printer_locations_expanded.png)]

**Клик по карточке группы** раскрывает список принтеров внутри.

**Каждый принтер отображает:**
- Статус-индикатор (зелёный = онлайн, оранжевый = печать, серый = оффлайн)
- Название и модель принтера
- Бейдж статуса (Printing / Paused / Finished / Idle / Offline)
- Кнопки управления: "Move", "Remove from group"

**Пустая группа** — показывает сообщение "No printers in this location"

## Перемещение принтера

[![Скриншот: Перемещение принтера](../docs/screenshots/printer_locations_move.png)]

**Кнопка:** "Move" (стрелка) рядом с принтером в раскрытой группе.

**Модалка перемещения:**
- Показывает имя перемещаемого принтера
- Выпадающий список с существующими группами
- Опция "Ungrouped" для удаления из группы
- Кнопки "Cancel" и "Move"

**Технические детали:**
- Использует `useMutation` с инвалидацией кэша `['printers']`
- При успехе показывается toast-уведомление "Printer moved"

---

## Удаление принтера из группы

**Кнопка:** "Remove from group" (UserMinus) — убирает принтер из группы без перемещения в другую.

Принтер перемещается в "Ungrouped Printers".

## Массовое удаление групп

[![Скриншот: Массовое удаление групп](../docs/screenshots/printer_locations_bulk_delete.png)]

**Шаг 1:** Нажать кнопку "Select" в верхней панели.

**Шаг 2:** Выбрать группы чекбоксами (стрелки раскрытия скрываются, заменяются на чекбоксы).

**Шаг 3:** Внизу появляется фиксированная панель с:
- Счётчиком выбранных групп
- Кнопкой "Delete selected" (красная)
- Кнопкой "Cancel"

**Шаг 4:** Подтверждение в модальном окне с указанием реального количества принтеров, которые будут разгруппированы.

**Технические детали:**
- При удалении автоматически очищаются кэш, иконки и цвета групп
- Модалка подтверждения закрывается после успешного удаления
- Режим выбора автоматически отключается

## Сортировка групп

[![Скриншот: Сортировка групп](../docs/screenshots/printer_locations_sort.png)]

**Кнопка:** "Name A→Z" со стрелкой ↕ в верхней панели.

**Выпадающее меню с 4 режимами:**
1. **Name A→Z** — по алфавиту (A-Z)
2. **Name Z→A** — по алфавиту (Z-A)
3. **Count ↑** — по количеству принтеров (возрастание)
4. **Count ↓** — по количеству принтеров (убывание)

**Особенности:**
- "Ungrouped" всегда первый, независимо от режима сортировки
- Выбор сохраняется в `localStorage` (`locationSortMode`)
- При сортировке по количеству — вторичная сортировка по имени для стабильности

## Фильтр пустых групп

[![Скриншот: Фильтр пустых групп](../docs/screenshots/printer_locations_hide_empty.png)]

**Кнопка:** "Hide empty" / "Show empty" в верхней панели.

- **Hide empty** — скрывает группы без принтеров
- **Show empty** — показывает все группы, включая пустые

**Технические детали:**
- Состояние сохраняется в `localStorage` (`hideEmptyGroups`)
- Восстанавливается при перезагрузке страницы

## Поиск групп

[![Скриншот: Поиск групп](../docs/screenshots/printer_locations_search.png)]

**Поле ввода** в верхней панели с иконкой лупы.

- Фильтрация по названию группы (case-insensitive)
- Работает в комбинации с фильтром "Hide empty"
- Пустая строка — показывает все группы

## Удаление группы

**Кнопка:** "🗑️ Delete" (корзина) справа от названия группы.

**Модалка подтверждения:**
- Название группы
- Количество принтеров, которые будут разгруппированы
- Кнопка "Delete" (красная)
- Кнопка "Cancel"

**Технические детали:**
- Все принтеры группы перемещаются в "Ungrouped"
- Автоматически удаляются кэш, иконка и цвет группы
- После удаления показывается toast "Location deleted"

## Архитектура

### State management
- **React Query** (`useQuery`, `useMutation`) — загрузка и кэширование данных принтеров
- **useState** — локальное состояние UI (модалки, выбор, сортировка)
- **localStorage** — персистентные настройки (сортировка, hideEmpty, кэш имён, иконки, цвета)

### Utils
- `printerLocationsCache.ts` — кэш имён групп для автодополнения
- `printerLocationIcons.ts` — мапа `locationName → iconName`
- `printerLocationColors.ts` — мапа `locationName → color`

### Мутации
| Мутация | Назначение |
|---------|-----------|
| `deleteLocationMutation` | Удаление одной группы |
| `editLocationMutation` | Переименование + смена иконки/цвета |
| `movePrinterMutation` | Перемещение одного принтера |
| `bulkMoveMutation` | Массовое перемещение принтеров |
| `bulkDeleteGroupsMutation` | Массовое удаление групп |
| `createLocationMutation` | Создание пустой группы |
| `removeFromGroupMutation` | Удаление принтера из группы |

### Сортировка
```typescript
type SortMode = 'name-asc' | 'name-desc' | 'count-asc' | 'count-desc';
```
Ungrouped всегда первый. Named группы сортируются по выбранному режиму.

### Хранение иконок и цветов
```
localStorage:
  printerLocationsCache   → string[]       (имёна групп)
  printerLocationIcons    → { [name]: string } (имя → iconName)
  printerLocationColors   → { [name]: string } (имя → color hex)
  locationSortMode        → SortMode
  hideEmptyGroups         → boolean
```
